# Mockup v2 — clickable screens

Open `index.html` in Chrome or Edge (fonts load from Google Fonts, so an internet connection helps).

- **Review bar** (bottom-left, dark): jump to any screen, and on game screens switch **Vòng 1 / 2 / 3** to see each tier. It is only for reviewing and is not part of the app. "☰ Mockup" collapses it.
- **Everything is playable**: drag or tap-then-tap fruit, run the robot, use the number pad, press **Xong** to see right/wrong feedback, press **i** for Mèo's guide.
- **Voice** is a placeholder: the browser's Vietnamese voice reads the prompts if one is installed (Edge usually has one). The real app uses the teacher's recordings.
- **Speaker button** mutes sound. In "Giỏ trái cây", muting shows the picture panel with the request.
- Pictures: Microsoft Fluent Emoji (MIT licence, see `assets/emoji/LICENSE-FluentEmoji.txt`). Mèo Smarty, the scales, baskets and vase are drawn in code.

Screens: Trang chủ · Chọn bạn · 1 Cái cân · 2 Rô-bốt · 3 Giỏ trái cây · 4 Tính theo hình · 5 Mấy và mấy · 6 So sánh cân · Nghỉ giữa giờ / Hết giờ / Mã PIN · Khu vực giáo viên (hold the padlock bottom-right of the homepage ~1 s, then PIN **1234**: effects, play time, students, backup).

Effects (animation, background pictures, confetti, sound effects) are switched in the teacher area → Hiệu ứng.
